(см. раздел 2) — он вынужденный, и это записано числом.

Наш объём 2,70 млн — в 700–5 800 раз ниже порога. **Доля общего пула** (без постоянной части): 1,31 $ за 1 млн — дешевле флагмана (1,52 $) при любом объёме и в 7 раз дороже дешёвого края (0,18 $) при любом объёме | **[оценка]** |

**Вывод одной строкой:** при нашем объёме 2,70 млн токенов в месяц API стоит 0,49–4,09 $/мес, доля общего пула H200
≈ 3,53 $/мес, выделенная H200 — 2 883,50 $/мес; выделенная карта сравнялась бы с API только при ~1,9–15,7 млрд
токенов в месяц, а доля пула дешевле флагмана при любом объёме — среду выбирает не цена (разница — единицы
долларов), а тайна в процессе и запрет внешних API: своё железо из общего пула [оценка].

подтверждается — только репутацией источника, контрольной суммой файла и нашими тестами (серия прогонов,
валидатор).
