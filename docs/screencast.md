# Сценарий финального скринкаста (до 5 минут)

Скринкаст — основное подтверждение работы системы и **гейт** проекта: на записи агент сам меняет внешнюю систему. Заодно запись подтверждает позиции 3.1 (запуск по событию или расписанию, без ручного шага) и 3.2 (результат виден в целевой системе, а не только в логе).

## Подготовка (до записи)

1. В n8n опубликованы BRD-01…BRD-08; в BRD-04 `ROLLOUT_STAGE = autonomous`, в BRD-03 `MAINTENANCE = false`.
2. Окна заранее открыты во вкладках:
   - Telegram — бот (роль заказчика) и чат команды;
   - Google Drive — папка «BRD Wiki» (отсортирована по дате);
   - Google Sheets «BRD agent — logs», лист `brd_registry`;
   - n8n — список Executions.
3. Лимит 5 боевых BRD за 24 часа не исчерпан. Отрепетируйте интервью один раз (реплики — [demo-scenario.md](demo-scenario.md), раздел 2).
4. **Не попадает в кадр:** адрес инстанса n8n, ключи и credentials, ID чатов, полные ссылки на документы Drive, адрес бота. Перед записью закройте лишние вкладки, после — пересмотрите запись.
5. Интервью длится 8–10 минут, генерация — 3–5 минут, поэтому ожидание **вырезаем при монтаже** или ускоряем ×4 с подписью «ускорено». Действия и результаты показываем без ускорения.

## Сценарий

| Время | Что на экране | Что говорить |
|---|---|---|
| 0:00–0:20 | титул deck или README | «BRD-агент: заказчик сам проходит интервью, BRD создаётся без встречи. Покажу полный цикл и запись в трёх внешних системах.» |
| 0:20–0:35 | Drive «BRD Wiki» и `brd_registry` — **до** | «Сейчас в папке и реестре нет нового документа — запомните последнюю строку.» |
| 0:35–2:15 | Telegram: `/start` → 6–8 реплик заказчика (ускорено, если долго). Обязательно: агент сам нашёл похожий сервис в реестре; вопрос про ChatGPT → агент предупреждает о конфликте с закрытым контуром; ответ «не знаю» | «Запуска руками нет: каждое сообщение заказчика — событие, на которое отвечает агент. Агент сам решает, когда идти в базу знаний: вот он нашёл похожий сервис…» |
| 2:15–2:35 | резюме от агента → «Да, всё верно» → «Формирую BRD…» | «Документ создаётся только после "да" заказчика — это точка контроля.» |
| 2:35–2:45 | (ожидание вырезано) ссылка на BRD в чате заказчика | «Через несколько минут — ссылка.» |
| 2:45–3:35 | **Google Drive** — новый Google Doc в «BRD Wiki» (время создания — только что); пролистать: 13 разделов, MLflow/GitLab отмечены, риск про ChatGPT, «не знаю» — в открытых вопросах | «Агент **создал документ** в папке-wiki — это запись во внешней системе, вторым окном, без агента.» |
| 3:35–3:55 | **Google Sheets** `brd_registry` — новая строка | «Строка в реестре BRD со статусом Draft — дальше согласование людьми.» |
| 3:55–4:10 | **Telegram**, чат команды — сообщение «Новый BRD» | «Команде **отправлено сообщение**.» |
| 4:10–4:40 | n8n → Executions: у BRD-05 (напоминания, каждый час) и BRD-01 (база знаний, каждую ночь в 03:00) запуски по расписанию, без Manual | «Без нас работает и расписание: напоминания заказчикам и обновление базы знаний — условие срабатывания повторяется само.» |
| 4:40–4:55 | слайд Cost или итог | «Один такой документ стоит около 4 центов против 12 часов встреч в неделю.» |

## Чек-лист после записи

- [ ] длина ≤ 5:00;
- [ ] видно действие во внешней системе: новый Google Doc **и** строка в `brd_registry` **и** сообщение в чат команды;
- [ ] видно, что запуск был по событию (сообщение заказчика) и по расписанию (Executions без Manual);
- [ ] ускоренные фрагменты подписаны;
- [ ] в кадре нет адреса инстанса, ключей, ID чатов, адреса бота и полных ссылок на документы.
